# Data Set

The data set is a collection of NRRD files used to test the projection algorithm.
It combines real data, synthetic data with known expected results, and invalid
files for error handling.

| ID | File | Size | Type | Purpose |
|----|------|------|------|---------|
| D1 | MRHead.nrrd (3D Slicer sample) | original | 16-bit | Visual check on real-world MRI data |
| D2 | synthetic_log.nrrd | 100x100x100 | 8-bit | "Tree trunk": value depends on distance from the central axis. A cross-section must show concentric circles, a lengthwise section must show stripes |
| D3 | synthetic_large.nrrd | 500x500x500 | 8-bit | Performance test (at least 30 fps) |
| D4 | synthetic_constant.nrrd | 20x20x20 | 8-bit | All voxels equal (min = max): tests division by zero |
| D5 | corrupt.nrrd | n/a | n/a | Invalid file: tests the error message |
| D6 | synthetic_log_16bit.nrrd | 100x100x100 | 16-bit | Same "tree trunk" with 16-bit values: tests 16-bit support and normalization |

## Notes
- Synthetic files are generated by a script (`make_dataset.py`), so they can be
  recreated and are not stored in the repository (the 500^3 file is about 125MB).
- The MRI file is downloaded from the 3D Slicer sample data.
- 8-bit (D2), 16-bit (D1, D6) are covered. A 32-bit file can be added later if needed.
