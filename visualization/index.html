איך נבנית התמונה

המישור מתואר כטרפז עם צלע עליונה A₀A₁ וצלע תחתונה B₀B₁. משולש הוא טרפז שהצלע העליונה שלו התכווצה לנקודה אחת, הקודקוד a. לכל פיקסל (i, j) בתמונה E מחושבת נקודה במישור באינטרפולציה בילינארית:

u = i/(W−1), v = j/(H−1) P(u,v) = (1−v)·[A₀ + u·(A₁−A₀)] + v·[B₀ + u·(B₁−B₀)] triangle (a,b,c): A₀ = A₁ = a, B₀ = b, B₁ = c |ab| = |ac| trapezoid (a,b,c,d): A₀ = a, A₁ = b, B₀ = d, B₁ = c ab ∥ dc, |ad| = |bc| W = round(max(|A₀A₁|, |B₀B₁|)) + 1 H = round(|mid(A₀A₁) − mid(B₀B₁)|) + 1 E[j][i] = M[round(Px)][round(Py)][round(Pz)] if inside M, else 0
  1. גודל התמונה נקבע לפי אורכי הצלעות בווקסלים, כך שכל פיקסל מתאים לערך ווקסל אחד בערך.
  2. בכל שורה מחושבים קצה שמאלי וקצה ימני, ואז מתקדמים בצעד קבוע לאורך השורה. זה מה שמאפשר קצב גבוה.
  3. הדגימה היא לפי הווקסל הקרוב ביותר. אינדקס מחוץ לטווח [0, s−1] בכל ציר מחזיר 0.
